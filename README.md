# GLHF

**GLHF** is a deliberately vulnerable Flask web application designed for hands-on security training. It guides you through a multi-stage challenge—**Lobby**, **User**, **Direct**, **Board**, and the hidden **Root** admin panel—each packed with realistic flaws to exploit.

**v0.1-beta**

```
docker pull coriscope/glhf:v0.1-beta
```
```
docker run -p 1337:1337 coriscope/glhf:v0.1-beta
```  
